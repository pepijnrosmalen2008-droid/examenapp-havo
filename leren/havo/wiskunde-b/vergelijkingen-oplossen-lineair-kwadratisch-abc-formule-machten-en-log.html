1Lineaire en kwadratische vergelijkingen

Een lineaire vergelijking los je op door haakjes weg te werken en x vrij te maken: 3(x − 2) + 4 = 2x + 5 geeft 3x − 2 = 2x + 5 en x = 7. Een kwadratische vergelijking los je op door te ontbinden of met de abc-formule: x² − 5x + 6 = 0 geeft (x − 2)(x − 3) = 0, dus x = 2 of x = 3. Het aantal oplossingen hangt af van b² − 4ac: positief twee, nul één, negatief geen. Controleer altijd door in te vullen.

Kies de methode die bij de vorm van de vergelijking past.
Onthoud: bij ax² + bx + c = 0 bepaalt b² − 4ac het aantal oplossingen.
2Oplossingen als snijpunten met de x-as

De oplossingen van x² − 5x + 6 = 0 zijn de nulpunten van f(x) = x² − 5x + 6: de grafiek snijdt de x-as bij x = 2 en x = 3. De top ligt bij x = 2,5 en f(2,5) = −0,25. Zo zie je ook dat twee oplossingen horen bij een parabool die de x-as snijdt. Bij 2x² − 3x − 2 = 0 geeft de abc-formule x = (3 ± 5)/4, dus 2 en −0,5.

De grafiek van f(x) = x² − 5x + 6 snijdt de x-as bij x = 2 en x = 3: dat zijn de oplossingen van de vergelijking.
Onthoud: de oplossingen van f(x) = 0 zijn de nulpunten van de grafiek.
3Wortel-, machts- en breukvergelijkingen

Bij machtsvergelijkingen gebruik je de logaritme: 5·2^x = 40 geeft 2^x = 8 en x = 3; ²log(x + 1) = 3 geeft x + 1 = 8 en x = 7. Bij een wortelvergelijking kwadrateer je, maar je krijgt een schijnoplossing: bij √x = x − 2 geeft kwadrateren x = 1 of x = 4, maar alleen x = 4 klopt. Bij een breuk vermenigvuldig je met de noemer en houd je x ≠ 0 in de gaten: 6/x = x + 1 geeft x = 2 of x = −3.

Een wortelvergelijking oplossen (eigen voorbeeld)

Los √x = x − 2 op. Kwadrateer: x = x² − 4x + 4, dus x² − 5x + 4 = 0 en x = 1 of x = 4. Controle in de oorspronkelijke vergelijking: bij x = 1 is √1 = 1 en 1 − 2 = −1. Bij x = 4 is √4 = 2 en 4 − 2 = 2. Dus x = 1 is een schijnoplossing.

4Werkwijze bij vergelijkingen

Herken eerst het type, kies de methode, los op en controleer door in te vullen in de oorspronkelijke vergelijking. Noteer bij een breuk x ≠ 0 en rond een exacte oplossing zoals 2 + √3 pas aan het eind af. Het verschil tussen 3,73 en 2 + √3 ontstaat door afronden.

Type herkennen, methode kiezen, oplossen en controleren in de oorspronkelijke vergelijking.
Tip: controleer in de oorspronkelijke vergelijking, ook na kwadrateren.

1. Welke x voldoet aan 2x + 5 = 13?

  1. "x = 9"
  2. "x = 4"
  3. "x = 6,5"
  4. "x = 3"
Antwoord en uitleg
  • A: Koos je ""x = 9""? Dan tel je 13 en 5 bij elkaar op. Eerst trek je 5 af, dus x = 4. Het goede antwoord is x = 4.
  • B (juist): Klopt: 2x = 8, dus x = 4. Reken dit na met de gegeven gegevens.
  • C: Koos je ""x = 6,5""? Dan deel je 13 door 2. Eerst trek je 5 af, dus x = 4. Door de stappen goed na te lopen kom je uit op x = 4.
  • D: Koos je ""x = 3""? Dan trek je 5 af en deel je door 3. Je deelt door 2, dus x = 4. Controleer je stap: de juiste uitkomst is x = 4.

Onthoud: Welke x voldoet aan 2x + 5 = 13?

Een leerling lost 3(x − 2) + 4 = 2x + 5 op. Hij werkt de haakjes weg, brengt de x-termen naar links en de getallen naar rechts en controleert zijn antwoord door in te vullen in de oorspronkelijke vergelijking.

2. Welke vergelijking krijg je na het wegwerken van de haakjes en het samennemen?

  1. "3x − 6 = 2x + 5"
  2. "3x + 2 = 2x + 5"
  3. "3x − 2 = 2x + 5"
  4. "3x − 10 = 2x + 5, zeg maar"
Antwoord en uitleg
  • A: Koos je ""3x − 6 = 2x + 5""? Dan vergeet je + 4. Links staat 3x − 6 + 4, dus 3x − 2. Het goede antwoord is 3x − 2 = 2x + 5.
  • B: Koos je ""3x + 2 = 2x + 5""? Dan maak je een tekenfout bij −6 + 4. Het is −2, dus 3x − 2. Door de stappen goed na te lopen kom je uit op 3x − 2 = 2x + 5.
  • C (juist): Klopt: 3x − 6 + 4 = 3x − 2. Reken dit na met de gegeven gegevens.
  • D: Koos je ""3x − 10 = 2x + 5, zeg maar""? Dan trek je 4 af in plaats van op te tellen. Het is − 6 + 4, dus 3x − 2. Controleer je stap: de juiste uitkomst is 3x − 2 = 2x + 5.

Onthoud: Welke vergelijking krijg je na het wegwerken van de haakjes en het samennemen?

Een leerling lost vergelijkingen met machten en logaritmen op: x³ = 27, 5·2^x = 40 en ²log(x + 1) = 3. Hij controleert elke oplossing door in te vullen in de oorspronkelijke vergelijking.

3. Bereken x uit x³ = 27.

  1. "x = 9"
  2. "x = 3 of x = −3"
  3. "x = 81"
  4. "x = 3"
Antwoord en uitleg
  • A: Koos je ""x = 9""? Dan deel je 27 door 3. Je zoekt een getal met derde macht 27, dus x = 3. Het goede antwoord is x = 3.
  • B: Koos je ""x = 3 of x = −3""? Dan denk je aan x² = 9. Bij een oneven macht is (−3)³ = −27, dus alleen x = 3. Door de stappen goed na te lopen kom je uit op x = 3.
  • C: Koos je ""x = 81""? Dan vermenigvuldig je 27 met 3. Je zoekt x met x³ = 27, dus x = 3. Controleer je stap: de juiste uitkomst is x = 3.
  • D (juist): Klopt: 3³ = 27 en een derde macht heeft hier één oplossing.

Onthoud: Bereken x uit x³ = 27.

Een leerling lost vergelijkingen met machten en logaritmen op: x³ = 27, 5·2^x = 40 en ²log(x + 1) = 3. Hij controleert elke oplossing door in te vullen in de oorspronkelijke vergelijking.

4. Isoleer eerst 2^x bij 5·2^x = 40. Welke x vind je?

  1. "x = 3"
  2. "x = 8"
  3. "x = 4"
  4. "x = 35, you know"
Antwoord en uitleg
  • A (juist): Klopt: 2^x = 8, dus x = 3. Reken dit na met de gegeven gegevens.
  • B: Koos je ""x = 8""? Dan stop je na het delen door 5. 2^x = 8 geeft x = 3, dus x = 3. Het goede antwoord is x = 3.
  • C: Koos je ""x = 4""? Dan deel je 40 door 10. Eerst delen door 5, dus 2^x = 8 en x = 3. Door de stappen goed na te lopen kom je uit op x = 3.
  • D: Koos je ""x = 35, you know""? Dan trek je 5 af van 40. Je moet delen door 5, dus x = 3. Controleer je stap: de juiste uitkomst is x = 3.
