1De raaklijn opstellen

De raaklijn in het raakpunt (a, f(a)) heeft als helling van de raaklijn het getal f'(a). Daarom is de vergelijking y = f'(a)(x − a) + f(a). Voor f(x) = x² − 4x + 5 is f'(x) = 2x − 4, dus f'(4) = 4 en f(4) = 5. De raaklijn is y = 4(x − 4) + 5 = 4x − 11. Controleer altijd of het raakpunt op de lijn ligt.

Afgeleide, helling, raakpunt en vergelijking van de raaklijn.
Onthoud: y = f'(a)(x − a) + f(a).
2Horizontale raaklijnen en extremen

Een horizontale raaklijn heeft helling 0, dus f'(x) = 0. De oplossingen zijn de x-waarden van de stationaire punten. Voor g(x) = −x² + 6x geldt g'(x) = −2x + 6 = 0 bij x = 3 en g(3) = 9: de top is (3, 9). De raaklijn in x = 1 is y = 4x + 1.

De top (3, 9) heeft de horizontale raaklijn y = 9; in (1, 5) is de raaklijn y = 4x + 1.
Tip: een horizontale raaklijn hoort bij f'(x) = 0.
3Extremen met een tekenschema

Voor h(x) = x³ − 12x geldt h'(x) = 3x² − 12 = 0 bij x = −2 en x = 2. In het tekenschema van f' is h' positief links van −2, negatief tussen −2 en 2 en positief rechts van 2. Dus wisselt h' bij x = −2 van + naar −: een lokaal maximum (−2, 16). Bij x = 2 wisselt h' van − naar +: een lokaal minimum (2, −16). Dit zijn de extremen. Geef bij een extreem ook de extreme waarde, dus de y-coördinaat.

Extremen bepalen met een tekenschema (eigen voorbeeld)

Bepaal de extremen van h(x) = x³ − 12x. Eerst h'(x) = 3x² − 12, dan x = −2 of x = 2. In het tekenschema is h'(−3) = 15, h'(0) = −12 en h'(3) = 15. Er is dus een maximum bij x = −2 met h(−2) = 16 en een minimum bij x = 2 met h(2) = −16.

4Controleren en interpreteren

Controleer elk extremum met een tekenschema: neem een x links en een x rechts van het stationaire punt en kijk of f' van teken wisselt. Bij W(q) = −q² + 8q − 7 is W'(q) = −2q + 8 = 0 bij q = 4 en W(4) = 9. De maximale winst is dus 9000 euro bij 400 stuks. Bij f(x) = x³ − 6x² + 9x geldt f'(x) = 3(x − 1)(x − 3), met een maximum (1, 4) en een minimum (3, 0), want f'(0) = 9 en f'(2) = −3.

Afgeleide, f' = 0, tekenschema en functiewaarde.
Tip: geef bij een extremum de x én de functiewaarde.

Oefen alvast: 4 vragen met uitleg

1. Welke formule geeft de raaklijn aan de grafiek van f in het punt met x = a?

  1. "y = f'(a)(x − a)"
  2. "y = f'(a)(x − a) + f(a)"
  3. "y = f(a)(x − a) + f'(a), denk ik"
  4. "y = f'(x)(x − a) + f(a)"
Antwoord en uitleg
  • A: Koos je ""y = f'(a)(x − a)""? Dan vergeet je het punt (a, f(a)). De lijn moet door het raakpunt gaan, dus y = f'(a)(x − a) + f(a).
  • B (juist): Klopt: de helling is f'(a) en de lijn gaat door het raakpunt (a, f(a)).
  • C: Koos je ""y = f(a)(x − a) + f'(a), denk ik""? Dan wissel je de functiewaarde en de helling. De helling is f'(a), dus y = f'(a)(x − a) + f(a).
  • D: Koos je ""y = f'(x)(x − a) + f(a)""? Dan laat je x staan in plaats van a. De helling is één getal, dus y = f'(a)(x − a) + f(a).

Onthoud: Welke formule geeft de raaklijn aan de grafiek van f in het punt met x = a?

Gegeven is f(x) = x² − 4x + 5. Een leerling bepaalt de afgeleide met de somregel, berekent de helling in het punt met x = 4, stelt de raaklijn op en zoekt het punt waar de raaklijn horizontaal is.

2. Welke afgeleide heeft f(x) = x² − 4x + 5?

  1. "f'(x) = 2x + 1, zeg maar"
  2. "f'(x) = x² − 4"
  3. "f'(x) = 2x − 4"
  4. "f'(x) = 2x + 4"
Antwoord en uitleg
  • A: Koos je ""f'(x) = 2x + 1, zeg maar""? Dan tel je de constante 5 mee. Die verdwijnt bij differentiëren, dus 2x − 4. Het goede antwoord is f'(x) = 2x − 4.
  • B: Koos je ""f'(x) = x² − 4""? Dan laat je de exponent niet verlagen. x² wordt 2x, dus 2x − 4. Door de stappen goed na te lopen kom je uit op f'(x) = 2x − 4.
  • C (juist): Klopt: 2x − 4 + 0. Reken dit na met de gegeven gegevens.
  • D: Koos je ""f'(x) = 2x + 4""? Dan vergeet je het minteken van −4x. De afgeleide is 2x − 4, dus 2x − 4. Controleer je stap: de juiste uitkomst is f'(x) = 2x − 4.

Onthoud: Welke afgeleide heeft f(x) = x² − 4x + 5?

Gegeven is g(x) = −x² + 6x. De grafiek is een bergparabool. Een leerling stelt de raaklijn op in het punt met x = 1 en zoekt de top van de parabool met g'(x) = 0.

3. Welke raaklijn hoort bij x = 1? Er geldt g(1) = 5.

  1. "y = 4x + 5, zeg maar"
  2. "y = 4x − 1"
  3. "y = 5x − 1"
  4. "y = 4x + 1"
Antwoord en uitleg
  • A: Koos je ""y = 4x + 5, zeg maar""? Dan vergeet je de − 4 · 1. y = 4(x − 1) + 5, dus y = 4x + 1. Het goede antwoord is y = 4x + 1.
  • B: Koos je ""y = 4x − 1""? Dan laat je het teken fout. y = 4x − 4 + 5, dus y = 4x + 1. Door de stappen goed na te lopen kom je uit op y = 4x + 1.
  • C: Koos je ""y = 5x − 1""? Dan wissel je f'(1) en g(1). De helling is 4, dus y = 4x + 1. Controleer je stap: de juiste uitkomst is y = 4x + 1.
  • D (juist): Klopt: g'(1) = 4, dus y = 4(x − 1) + 5. Reken dit na met de gegeven gegevens.

Onthoud: Welke raaklijn hoort bij x = 1? Er geldt g(1) = 5.

Gegeven is h(x) = x³ − 12x. Een leerling lost h'(x) = 0 op, maakt een tekenschema van h' en bepaalt de coördinaten van het lokale maximum en het lokale minimum. Daarna stelt hij ook de raaklijn op in het punt met x = 1.

4. Welke x-waarden geven h'(x) = 3x² − 12 = 0?

  1. "x = −2 en x = 2"
  2. "x = 4 en x = −4, eigenlijk"
  3. "alleen x = 2"
  4. "x = 6"
Antwoord en uitleg
  • A (juist): Klopt: x² = 4. Reken dit na met de gegeven gegevens.
  • B: Koos je ""x = 4 en x = −4, eigenlijk""? Dan vergeet je de wortel te nemen. x² = 4 geeft x = ±2, dus x = −2 en x = 2. Het goede antwoord is x = −2 en x = 2.
  • C: Koos je ""alleen x = 2""? Dan vergeet je x = −2. x² = 4 heeft twee oplossingen, dus x = −2 en x = 2. Door de stappen goed na te lopen kom je uit op x = −2 en x = 2.
  • D: Koos je ""x = 6""? Dan deel je 12 door 2. 3x² = 12 geeft x² = 4, dus x = −2 en x = 2. Controleer je stap: de juiste uitkomst is x = −2 en x = 2.
